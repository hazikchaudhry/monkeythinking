Challenge: Extend the App

Finished the base app? Try one of these.

1. Add More Memes

Detect a peace sign (index + middle extended) and load a new meme.

2. Change Circle Color

Make the landmark circles blue instead of green: (255, 0, 0).

3. Add Text Display

Use cv2.putText() to show "POINTING!" on screen.

4. Try Different Gestures

Experiment with thumbs up or an open palm.
