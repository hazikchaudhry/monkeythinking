Setup

Get your machine ready before we start coding.

What are you on?

  1. Clone the repo, then cd monkeythinking
  2. Run ./setup.sh
  3. No uv? It prints a one-line install command:
    curl -LsSf https://astral.sh/uv/install.sh | sh
    Run it, restart your terminal, then re-run ./setup.sh
  4. uv sync runs — installs the pinned dependencies, fetching a matching Python for you if you don't already have one
  5. Confirm you see All required files present.
  6. First time you run the app, macOS asks for camera permission — click Allow. Missed it? System Settings → Privacy & Security → Camera
  7. Can't install uv? Run ./setup-pip.sh instead — same checks, plain venv + pip (needs Python 3 already on the machine)
