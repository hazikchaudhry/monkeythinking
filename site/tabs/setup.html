Setup

Get your machine ready before we start coding.

Get the project

Everything for this workshop lives in the Monkey Thinking GitHub repository.

git clone https://github.com/hazikchaudhry/monkeythinking.git
cd monkeythinking

Run these commands once in Terminal (macOS/Linux), PowerShell, or Command Prompt (Windows) before following the setup steps below.

What are you on?

  1. Clone the repo, then cd monkeythinking
  2. Run ./setup.sh
  3. No uv? It prints a one-line install command:
    curl -LsSf https://astral.sh/uv/install.sh | sh
    Run it, restart your terminal, then re-run ./setup.sh
  4. uv sync runs — installs the pinned dependencies, fetching a matching Python for you if you don't already have one
  5. Confirm you see All required files present.
  6. First time you run the app, macOS asks for camera permission — click Allow. Missed it? System Settings → Privacy & Security → Camera
  7. Can't install uv? Run ./setup-pip.sh instead — same checks, plain venv + pip (needs Python 3 already on the machine)

Run the starter project

After setup finishes, open starter_code.py, fill in the blanks, then run:

uv run python starter_code.py

Using the pip fallback instead? Activate .venv first, then run python starter_code.py. Press q to close the camera window.

Solution files Open when you need a hint or want to compare your work

The finished starter-project answer is solutions/solution.py. Run it with:

uv run python solutions/solution.py
  • solution.py — completed starter project
  • main.py — an earlier working version
  • workshop_simple.ipynb — the project as a Jupyter notebook
  • devs.py — the extended DEVS version
